# 🥚 Easter Eggs Guide

This portfolio has hidden easter eggs that can be triggered in different ways on desktop and mobile!

## 🎬 AVG Cinematic Mode

A dramatic cinematic animation that plays across the screen.

### Desktop
- **Trigger**: Type `avg` anywhere on the page (not in input fields)
- The letters don't need to be typed quickly, just in sequence

### Mobile
- **Trigger**: Long press (hold your finger) anywhere on the screen for 2 seconds
- Don't press on buttons, links, or input fields
- You'll feel a vibration when it triggers (if your device supports haptic feedback)
- Keep your finger still - moving it will cancel the trigger

## 🐛 Bug Mode

A glitch effect that makes the page look "buggy" for 3 seconds.

### Desktop
- **Trigger**: Type `bug` anywhere on the page (not in input fields)
- The letters don't need to be typed quickly, just in sequence

### Mobile
- **Trigger**: Triple tap anywhere on the screen quickly (within 500ms between taps)
- Don't tap on buttons, links, or input fields
- You'll feel a vibration pattern when it triggers (if your device supports haptic feedback)
- Tap 3 times in quick succession

## 🎹 Piano Sounds (Mobile Only)

On mobile devices, the "Explore Skills" section has interactive piano sounds!

### Mobile
- **Trigger**: Tap on any skill card in the "Explore Skills" section
- Each skill card plays a unique chord progression
- The "Explore Skills" label itself plays a C major scale melody

## 💡 Tips

- These easter eggs are designed to be discovered naturally while browsing
- They won't interfere with normal navigation or form inputs
- On mobile, haptic feedback helps confirm when you've triggered an easter egg
- The AVG cinematic can only be triggered once per page load (refresh to try again)
- Bug mode automatically turns off after 3 seconds

## 🔒 Content Protection

The site also has content protection features:
- Text selection is disabled
- Right-click context menu is disabled
- Images cannot be dragged
- Copy/paste keyboard shortcuts are blocked
- DevTools shortcuts are blocked

These features protect the portfolio content while maintaining a good user experience.
